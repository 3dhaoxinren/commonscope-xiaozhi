# 初版 CommonScope TXW818 拍照屏：第一次刷机与设备热点

**只适用于本项目同版的 CommonScope TXW818 绿板。** 这是原拍照屏远程更新的网络入口，不是 ESP32-C3 的小智配网热点。先确认板号和当前固件；本项目早期记录的原机主控版本为 1.1.x，后续自研绿板为 B07 系列，不能只看外壳来推断兼容性。

## 1. 首刷前确认

- 原绿板先保持独立、稳定供电。未确定电源与串口关系前，先不接 C3。对不同批次，先核对板级标识和厂商升级界面识别的目标。备份有权保存的原始固件与设备配置；不要把单个 OTA BIN 当作整片 Flash 恢复备份。
- 通过原机正常界面启动 Wi-Fi／无线传图功能，以设备实际显示的二维码或 Wi-Fi 名称为准。测试机的设备热点命名为 CommonScope-XXXXXX；后缀每台不同。不同原厂版本的具体按键入口未在本仓统一验证。看不到设备热点，先回原机正常界面核对无线功能或厂商 App 的操作说明，不要猜按键去刷机。
- 手机 Wi-Fi 连接自己的设备热点。出现没有互联网的系统提示时选择保持连接。[CommonScope 厂商 App](https://play.google.com/store/apps/details?id=cn.com.buildwin.general)用于核对这条原机 Wi-Fi 路径；[TXW818 厂商手册](https://www.taixin-semi.com/en/docs/txw818/latest/TXW818%20%E6%95%B0%E6%8D%AE%E6%89%8B%E5%86%8C?navigation=1&series=txw81x)可用来核对芯片和板级接口，不能代替成品的升级说明。

## 2. 第一刷：走该板正常升级路径

1. 用该机厂家支持的升级界面核对目标、版本和原机热点连接，再选型号、分区、容量和来源均已核对的固件。绿板和 C3 的镜像不能互换；实验包、差分、诊断包和普通 OTA 不是同一种东西。
2. 确认有回退方案和稳定供电后才写入；等待升级完成和实际重启。传输 100% 不代表已经成功启动。
3. 重启后回到初版的无线传图或 Wi-Fi 入口，重新连接屏幕自己的热点。核对版本、画面、按键和是否还能正常无线连接，再接 C3。若第一刷后热点没出现或版本、电路不匹配，先停在这一步；不要重复刷不同机型试错。
4. 本仓没有独立可刷的原绿板首刷镜像。仅有本仓文件时，能核对流程和运行公开的主机测试，但**不能完成绿板首刷**。需要对应批次、来源明确的授权镜像。 见 [底包获取与开机热点源码合并](txw818-base-and-boot-ap.md)。

在本项目**已经安装并支持 Wi-Fi 回切的自研版本**中，回到亮屏空闲界面后同时长按原机音量 ＋／－约 3 秒，是回到设备热点的入口。此手势不是通用原厂操作，也不用于 C3 首次配网或空板刷写。

公开代码见 [Wi-Fi 状态机](../firmware/panel/wifi/wifi_runtime.c)。该模块保留或回退 AP，拒绝重叠网段及无 DHCP 的接入；与 TXW818 厂商网络接口的集成不包含在内。配网、OTA 与设备恢复分开验收。
