# 公开范围和验证

## 本仓可复查的结果

- **C3 源码集成：** 在固定的小智上游提交的两个独立干净 checkout 上，分别应用 `prototype` 与 `current`；两套增量应用成功，Git 空白检查通过。
- **主机测试：** 使用 Zig 的 C 编译器运行 `tools/run-host-tests.py`，通过 75 项双板协议／租约／手势检查、31 个按键手势样本、6 个 AP／STA 场景；同时把绿板按键模块编译为独立目标文件。AP／STA 测试使用模拟网络端口，不需要真实设备，也不会发起真实网络连接或刷机。
- **实机边界：** 历史实机曾读取绿板 B07F、C3 6.4.3；这是项目之前的设备版本记录，不是本次公开快照的整机复刷验收。本次不写入硬件。绿板初次刷写仍需要板型匹配、有权使用的镜像，本仓没有该镜像。

在本仓根目录复跑：

    python tools/run-host-tests.py

如系统没有 `cc`，安装 C 编译器后用 `--cc` 指定其可执行文件（支持 Clang、GCC 与 Zig）。C3 复现命令见 [构建和首次启动](c3-build-and-first-boot.md)。

## 没有公开的内容

厂商绿板固件和 SDK、完整设备 Flash 和 NVS、已配对维护凭据、签名材料及未确认可重分发的唤醒模型均未收录。绿板 Wi-Fi 和按键模块需要目标板适配层；主机测试结果不等于原厂任意批次刷写成功。
